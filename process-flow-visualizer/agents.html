NARRATIVE DESIGN 叙事设计

纯文本推理：从创意简报到结构化故事蓝图与分镜剧本。

📖
StoryAgent Pure LLM

从自然语言创意简报生成结构化故事蓝图：logline、角色表、场景大纲、地点、故事弧线。

Inputcreative_brief (自然语言描述)
Outputstory_blueprint (logline, cast, locations, scene_outline)
完整可用
🎬
ScreenplayAgent Pure LLM

将故事蓝图展开为完整分镜剧本：按场景/镜头拆分，含对白、视觉方向、一致性包。

Inputstory_blueprint (cast, locations, scene_outline)
Outputscreenplay (scenes → shots: script + visual plan + consistency)
完整可用
📋
UnivaStoryboardAgent Pure LLM

UniVA 风格 storyboard 规划：从 creative brief 生成角色定义 + 逐镜头分解。

Inputcreative_brief
Outputuniva_storyboard (characters[], shots[], style)
完整可用
MEDIA GENERATION 媒体生成

调用外部生成服务，产出图像、视频片段与音频包。

🖼
KeyFrameAgent LLM + Media

三层关键帧系统：L1 全局身份图、L2 场景锚定帧、L3 每镜头静帧 + motion hint。调用图像生成服务。

Inputscreenplay (shots + consistency packs)
Outputkeyframes_package (L1/L2/L3 stills + motion hints)
完整可用
🎥
VideoAgent LLM + Media

逐镜头生成视频片段：关键帧 + motion hint → I2V 模型生成 → 拼接为连续视频。

Inputscreenplay + per-shot keyframe images
Outputvideo_package (shot clips + scene clips + merged video)
完整可用
🖼
UnivaKeyFrameAgent LLM + Media

UniVA 风格关键帧生成：角色参考图 + 逐镜头关键帧图。

Inputuniva_storyboard
Outputuniva_keyframes (character refs + per-shot images)
完整可用
🎥
UnivaVideoAgent LLM + Media

UniVA 风格视频生成：从逐镜头关键帧生成 I2V 视频片段并合并。

Inputuniva_storyboard + univa_keyframes
Outputuniva_video (per-shot clips + merged video)
完整可用
POST-PRODUCTION 后期合成

将散装素材（视频片段 + 音频 + 字幕）合成为最终可交付视频。补完生产链的最后一公里。

💬
SubtitleAgent Pure LLM

从剧本对白/旁白生成带时间戳的 SRT 字幕轨。支持按视频时间线对齐，自动断行和阅读速度控制。

Inputscreenplay + optional video_package (timing)
Outputsubtitle_tracks (SRT cues with timing)
纯 LLM — 完整可用
🎞
CompositorAgent LLM + Media

最终合成：视频 + 音频 mux、字幕烧录、镜头间转场（cut/crossfade/fade）、统一调色，输出可交付 MP4。

Inputvideo_package + audio_package + subtitle_tracks + screenplay
Outputfinal_video (composited MP4)
E2E 通过 — FFmpeg 合成 (mock + real)
LOCALIZATION 多语言 / 本地化

翻译、转录、多语言配音和字幕。支持「中文视频 → 英文视频」完整链路。

🌐
TranslationAgent Pure LLM

翻译结构化文本（剧本、转录、故事蓝图），保留所有结构性 key（scene_id, shot_id 等）不变，只翻译人可读内容。

Inputsource_text (any structured artifact) + target_language
Outputtranslation (translated text, structure preserved)
纯 LLM — 完整可用
🎙
TranscriptionAgent LLM + Media

语音转文字：从音频/视频提取带时间戳的逐句转录，支持说话人识别和语言检测。

Inputsource_media (audio/video file)
Outputtranscript (segments with timestamps + speaker + full_text)
E2E 通过 — OpenAI Whisper (mock + real)
VIDEO EDITING 视频二次编辑

对已有视频进行内容级修改：风格迁移、物体替换、深度分离编辑、视频续写。

🎨
StyleTransferAgent LLM + Media

视觉风格迁移：将写实视频变为动漫/水彩/油画/赛博朋克等风格，保留原始运动轨迹。可强度可控。

Inputsource_video + style_reference (image or description)
Outputstylized_video (MP4 with new visual style)
E2E 通过 — fal.ai video edit (mock + real)
🖌
InpaintAgent LLM + Media

视频重绘 / 物体替换。支持四种 mask 模式：手动 mask、深度前景、深度背景（前景不动改背景或反之）、物体追踪。

Inputsource_video + mask (manual/depth_fg/depth_bg/object) + description
Outputinpainted_video (replaced region blended into source)
E2E 通过 — fal.ai video edit (mock + real)
⏩
VideoExtendAgent LLM + Media

视频续写：从源视频末帧出发，按文字描述继续生成新片段。可复用现有 I2V video_service。

Inputsource_video + continuation_description
Outputextended_video (continuation clip, 3-10s)
E2E 通过 — FFmpeg 帧提取 + I2V (mock + real)
VIDEO UNDERSTANDING 视频理解 + 搜索

对视频内容进行深度分析、场景检测、精选裁剪。

🔍
VideoAnalysisAgent LLM + Vision

视频深度分析：场景边界检测、逐场景视觉描述、实体识别、内容摘要。纯 LLM + vision，无需外部服务。

Inputsource_video
Outputvideo_analysis (scenes, descriptions, entities, summary)
纯 LLM+Vision — 完整可用
✂️
HighlightAgent LLM + Media

精选裁剪：基于给定标准（"动作场景"、"最佳画面"等）从视频中选取最佳片段，编译为精华集锦。

Inputsource_video + optional video_analysis + criteria
Outputhighlight_reel (curated clips compiled into reel)
E2E 通过 — FFmpeg clip + concat (mock + real)
VOICE / AUDIO 语音 / 音频

TTS 旁白、背景音乐、环境音、混音、语音克隆。每个 agent 只处理一种音频轨，由 AudioMixAgent 混合。

🎤
NarrationAgent LLM + Media

逐 shot 对白/旁白 → TTS 语音生成。从剧本提取每句台词，调用 TTS 服务合成语音。

Inputscreenplay (dialogue/narration text)
Outputnarration_segments (per-shot WAV)
E2E 通过 — fal.ai TTS
🎵
MusicAgent LLM + Media

逐 scene 生成背景音乐。从剧本的场景 mood/tone 推导音乐风格和配器。

Inputscreenplay (scene mood/tone)
Outputmusic_cues (per-scene WAV)
E2E 通过
🌊
AmbienceAgent LLM + Media

逐 scene 生成环境音。从剧本的场景地点/环境推导背景声（风声、雨声、城市噪音等）。

Inputscreenplay (scene location/setting)
Outputambience_beds (per-scene WAV)
E2E 通过
🎚
AudioMixAgent LLM + Media

混音 + 拼接：将旁白、音乐、环境音三轨混合为逐场景混音，再拼接为最终音频。

Inputnarration + music + ambience tracks
Outputaudio_mix (per-scene mix + final audio WAV)
E2E 通过
🗣
VoiceCloneAgent LLM + Media

语音克隆：从参考音频提取声纹，用克隆声音朗读给定文本。替代 NarrationAgent 使用。

Inputreference_audio (voice sample) + transcript
Outputvoice_clone_narration (segments in cloned voice + final audio)
E2E 通过 — fal.ai F5-TTS
INTAKE 用户上传 Intake

将用户原始上传（文本/图片/视频/音频）转为 caption-rich workspace artifact，供下游 agent 通过语义标签召回。

📝
IntakeTextAgent Pure LLM

分析用户上传的文本，生成描述性 caption 并分类（creative brief / reference / etc）。

完整可用
🏞
IntakeImageAgent LLM + Vision

Vision LLM 分析上传图片，生成视觉描述 + 用途分类 caption。

完整可用
📹
IntakeVideoAgent LLM + Vision

分析上传视频，生成内容描述 caption。

完整可用
🎵
IntakeAudioAgent Pure LLM

分析上传音频，生成内容描述 caption。

完整可用
🔗
BriefEnricherAgent Pure LLM

将上传图片的视觉描述织入用户 creative brief，并分类每张图的角色（character / location / prop / style），使下游 StoryAgent 生成的角色描述匹配参考图。

Inputcreative_brief + image_payloads (from IntakeImageAgent)
Outputenriched_brief + image_classifications (role + entity_hint per image)
完整可用
