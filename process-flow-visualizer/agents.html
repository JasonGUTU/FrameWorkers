NARRATIVE DESIGN 叙事设计

纯文本推理：把创意简报拆成结构化故事蓝图 / 分镜剧本（电影多镜头流）或 illustration-aligned 叙事脚本（illustrated-storytelling 流）。

📖
StoryAgent Pure LLM

从自然语言创意简报生成结构化故事蓝图：logline、角色表、场景大纲、地点、故事弧线。

Inputcreative_brief (自然语言描述)
Outputstory_blueprint (logline, cast, locations, scene_outline)
完整可用
🎬
ScreenplayAgent Pure LLM

将故事蓝图展开为完整分镜剧本：按场景/镜头拆分，含对白、视觉方向、一致性包。

Inputstory_blueprint (cast, locations, scene_outline)
Outputscreenplay (scenes → shots: script + visual plan + consistency)
完整可用
📓
NarrationAgent Pure LLM

illustrated-storytelling / audiobook-with-pictures 的创意头：把 creative brief 拆成「一张图一段故事」的 illustration-aligned segments，每段带 image_prompt + 逐行 TTS 文本 + 跨段 art-style 锚点。电影 / 多镜头流不走这里（那条走 Screenplay）。

Inputcreative_brief
Outputnarration_script (language + overall_style + segments · image_prompt · per-line TTS text)
完整可用
MEDIA GENERATION 媒体生成

调用外部生成服务，产出图像、视频片段与音频包。

🖼
KeyFrameAgent LLM + Media

三层关键帧系统：L1 全局身份图、L2 场景锚定帧、L3 每镜头静帧 + motion hint。调用图像生成服务。

Inputscreenplay (shots + consistency packs)
Outputkeyframes_package (L1/L2/L3 stills + motion hints)
完整可用
🎥
VideoAgent LLM + Media

逐镜头 Kling I2V 生成 + 逐场景 / 全片拼接。Kling 的 generate_audio 会把角色对白和画面 foley 直接烘进每段 clip 的音轨，这些不由 music / ambience / audio_mix 另出；BGM 和环境底另起 agent 后期叠加。

Inputscreenplay + per-shot keyframe images
Outputvideo_package (shot clips · scene clips · merged film; clips 自带 dialogue + foley 音轨)
完整可用
📚
IllustrationAgent LLM + Media

illustrated-storytelling 插画生成：按 narration script 的 segments 逐段出图，首帧作为跨段风格锚点（first-frame-as-anchor）保证整本风格一致。

Inputnarration_script (segments + per-segment image_prompt + overall_style)
Outputillustration_manifest (one PNG per segment, style-consistent)
完整可用
POST-PRODUCTION 后期合成

将散装素材（视频片段 + 音频 + 字幕）合成为最终可交付视频。补完生产链的最后一公里。

💬
SubtitleAgent Pure LLM

从定时文本源生成 SRT 字幕轨：源可以是 screenplay 的对白（新建流），也可以是 transcript（已有视频加字幕流）。两条路径 schema 兼容，走同一个 label。

Inputscreenplay OR transcript（其一，带 timing）
Outputsubtitle_tracks (SRT cues with timing, one track per language)
纯 LLM — 完整可用
🎞
CompositorAgent LLM + Media

最终合成：视频 + 音频 mux、字幕烧录、镜头间转场（cut/crossfade/fade）、统一调色，输出可交付 MP4。

Inputvideo_package + audio_package + subtitle_tracks + screenplay
Outputfinal_video (composited MP4)
E2E 通过 — FFmpeg 合成 (mock + real)
LOCALIZATION 多语言 / 本地化

翻译、转录、多语言配音和字幕。支持「中文视频 → 英文视频」完整链路。

🌐
TranslationAgent Pure LLM

翻译结构化文本（SRT、screenplay 等），保留所有 keys / ids / timing / ordering — 例如译后 SRT 每条 cue 的时间戳原样保留。必须在已出 SRT 后再跑（把 raw transcript 先翻译再断句会破坏时间戳）。

Inputsubtitle_tracks (SRT) + target_language
Outputtranslation (结构保持，cue 时间戳原样保留)
纯 LLM — 完整可用
🎙
TranscriptionAgent LLM + Media

已有视频音轨 → 语音转文字：带时间戳的逐句 transcript + 整段 full_text + 检测到的语言。输出 shape 与 SubtitleAgent 的 timed-source 输入兼容，可直接被 SubtitleAgent 当作 screenplay 的替代喂入。

Inputsource_media (audio/video file)
Outputtranscript (timestamped segments + full_text + detected language)
E2E 通过 — OpenAI Whisper (mock + real)
VIDEO EDITING 视频二次编辑

对已有视频进行内容级修改：风格迁移、物体替换、深度分离编辑、视频续写。

🎨
StyleTransferAgent LLM + Media

视觉风格迁移：将写实视频变为动漫/水彩/油画/赛博朋克等风格，保留原始运动轨迹。可强度可控。

Inputsource_video + style_reference (image or description)
Outputstylized_video (MP4 with new visual style)
E2E 通过 — fal.ai video edit (mock + real)
⏩
VideoExtendAgent LLM + Media

给已有 clip 延时长：慢动作、氛围插入、特写、音效叠加等电影化手法，无缝续在源视频末尾。**不是叙事续写**（下一场剧情要走 Story 链），产出本身即是可交付成品。

Inputsource_video + 延长意图描述
Outputextended_video (continuation 段无缝 append 到源)
E2E 通过 — FFmpeg 帧提取 + I2V (mock + real)
VIDEO UNDERSTANDING 视频理解 + 搜索

对视频内容进行深度分析、场景检测、精选裁剪。

🔍
VideoAnalysisAgent LLM + Vision

视频深度分析：场景边界检测、逐场景视觉描述、实体识别、内容摘要。纯 LLM + vision，无需外部服务。

Inputsource_video
Outputvideo_analysis (scenes, descriptions, entities, summary)
纯 LLM+Vision — 完整可用
✂️
HighlightAgent LLM + Media

精选裁剪：基于给定标准（"动作场景"、"最佳画面"等）从视频中选取最佳片段，编译为精华集锦。

Inputsource_video + optional video_analysis + criteria
Outputhighlight_reel (curated clips compiled into reel)
E2E 通过 — FFmpeg clip + concat (mock + real)
VOICE / AUDIO 语音 / 音频

BGM / 环境底 / 混音，加 illustrated-storytelling 专用 narrator voiceover。Music 和 Ambience 各出一条 film-wide 单轨，由 AudioMixAgent 叠上 Video 自带的 Kling dialogue+foley 轨合并成终轨。

🎵
MusicAgent LLM + Media

生成 ONE film-wide 背景音乐轨。新建影片默认触发（除非用户只要 ambience），或已有视频上要求 BGM / soundtrack / score 时触发。

Inputscreenplay (整体 mood/tone)
Outputmusic_track (film-wide WAV)
E2E 通过
🌊
AmbienceAgent LLM + Media

生成 ONE film-wide 环境底（room tone / 氛围底噪）。影片默认和 music 并行触发（除非只要 music），或已有视频要求铺雨声 / 风声 / 人群底噪时触发。

Inputscreenplay (整体 setting / 环境描述)
Outputambience_bed (film-wide WAV)
E2E 通过
🎚
AudioMixAgent LLM + Media

把视频自带的 Kling dialogue+foley 轨 + 可选 music + 可选 ambience 三路 amix 成 ONE film-wide 终轨（sys_id = aud_final），给 Compositor 用。

Inputvideo_package audio + optional music + optional ambience
Outputaudio_mix (film-wide final WAV, sys_id=aud_final)
E2E 通过
🔊
NarratorAgent LLM + Media

illustrated-storytelling 旁白渲染：逐行 TTS 带停顿拼成连续 narrator wav，同时产出行级 SRT 和 per-segment timing（给 slideshow compositor 用来决定每张插画停留多久）。

Inputnarration_script (segments + lines + pause_after_ms)
Outputnarrator_voiceover (full WAV + timed SRT + per-segment timing)
E2E 通过 — fal.ai TTS
INTAKE 用户上传 Intake

将用户原始上传（文本/图片/视频/音频）转为 caption-rich workspace artifact，供下游 agent 通过语义标签召回。

📝
IntakeTextAgent Pure LLM

Pipeline 根节点：任何带文字的用户请求都 FIRST 跑这个（即几乎每一轮用户输入）。把 raw 文本落成带 caption 的 workspace artifact（creative brief），供下游按 label 召回。

完整可用
🏞
IntakeImageAgent LLM + Vision

上传图像 → Vision LLM caption，作为 character / location / style reference artifact 落盘，下游按 semantic-typed image label（如 [character_reference] / [style_reference]）召回。

完整可用
📹
IntakeVideoAgent LLM + Vision

上传视频 → 落成带 caption 的 workspace artifact，供下游任何视频消费 agent（analysis / style transfer / extend / highlight / transcription / subtitle）按 label 召回。

完整可用
🔗
BriefEnricherAgent Pure LLM

将上传图片的视觉描述织入用户 creative brief，并分类每张图的角色（character / location / prop / style），使下游 StoryAgent 生成的角色描述匹配参考图。

Inputcreative_brief + image_payloads (from IntakeImageAgent)
Outputenriched_brief + image_classifications (role + entity_hint per image)
完整可用
