核心机制

多模态输入流

  1. 文字：IntakeTextAgent 包装 → 成为 creative brief
  2. 图片：IntakeImageAgent vision LLM 理解 → 产出视觉描述
  3. 融合（有图时）：BriefEnricherAgent 读用户文字 + 图片描述 → 从文字上下文判断图片角色（character / location / prop / style）→ 把视觉描述注入 brief → enriched brief 替代原始 brief
  4. 参考图作为 L1 anchor：BriefEnricherAgent 给图片注册 role-specific caption → InputResolver 匹配到 KeyFrameAgent 的 [character_reference] label → 用户照片跳过文生图，直接成为角色的视觉锚点

Sub-agent 解耦通信

  1. 输入：所有 agent 的输入字段都是 *_json_text: str，上游 JSON 整块序列化成文本传入，consumer 的 LLM 自主理解形状。Python 层零 .get() 链，零跨 agent 耦合
  2. 输出：producer 严控自己的 Pydantic schema，evaluator 通过 structural check + rework 保证格式正确
  3. 路由：生产者写 caption（资产属性），消费者写 [label] 描述，InputResolver 的 LLM 做自然语言语义匹配。无硬编码路由规则
  4. 重跑替换：同一 (task_id, agent_id) 只保留一份输出。重跑时 prune 旧产物 + 写新产物，用户原始上传永不删除
