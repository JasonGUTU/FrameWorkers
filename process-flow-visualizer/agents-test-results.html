Sub-Agent × API 对照表

LLM 层：所有 agent 共用一条路径——LLMClient → Cloudflare AI Gateway (CF_AIG_TOKEN / CF_AIG_BASE_URL) → 上游模型 google-ai-studio/gemini-2.5-flash（OpenAI 兼容 SDK 直连，不走 OpenRouter）。多模态（图片/视频/音频）都是把媒体 base64 化塞进 chat.completions 的 multimodal content array 里。
