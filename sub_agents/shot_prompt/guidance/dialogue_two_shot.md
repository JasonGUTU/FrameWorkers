# dialogue_two_shot

> 适用场景：双人 / 多人对白 —— 交锋 / 倾诉 / 审讯 / 谈判 / 告白。lip-sync 关键。

## STYLE HEADER 候选词
双人对话 / OTS 过肩镜 / 180 度轴线 / 反应镜头 / 对白节奏 / 中景 + 特写交替

## 词汇表

**机位 / framing**：A 主角 OTS（B 肩在前景虚化）/ 切 B OTS / 双人 medium two-shot / 切单人特写（强调情绪）/ 反应镜头（听话人特写）/ 180 度轴线严守

**对白节奏标记**：A 说话时 B 沉默听 / 抢话（A 未说完 B 切入）/ 长停顿（A 说完后空 2 秒 B 才反应）/ 同时开口（彼此抢话）

**lip-sync 要求**：明确写出 A 说："xxx"；B 答："xxx"；模型按时间序列对口型

**身体语言**：A 前倾施压 / B 后仰回避 / A 双手插袋假装放松 / B 手指敲桌一次（紧张）/ A 抬手做停止手势 / B 低头不看 A

**视线交换**：A 直视 B / B 视线游移到 A 嘴唇又回到眼睛 / A 别开视线再扫回 / 两人对视后同时移开

**镜头**：A 说话时锁 A 特写，B 反应时切 B 特写；不要频繁切（每句话切 1 次最多）；推进只在情绪升点

## panel 节奏建议
- 4-panel 推荐结构：**A 起话 → B 反应 → B 反击 / 回应 → A 沉默 / 表情结束**
- 每 beat 必须包含：
  1. 机位（OTS / 单人 / two-shot）+ 主体是谁
  2. 对白内容（双引号写出，含语气）+ 节奏标记（停顿 / 抢话）
  3. 听话方的反应（表情 / 身体语言 / 视线）
- 关键约束：**180 度轴线**全 shot 不跨越；模型容易破轴
- 避免：长段独白（拆到 INNER_MONOLOGUE_VO） / 没有反应镜头 / 没有 lip-sync 文本

## SFX 词汇
对白清晰人声 / 环境室内反射 / 桌面轻响 / 椅子吱呀 / 远处闷音 / 空调底噪 / 雨声窗外 / 钟摆

## 反面教材
❌ "两人激烈争吵"                — 没对白文本，模型嘴型乱动
✅ 'A 中景 OTS：A 前倾说："你早就知道了，对不对？" 语气低压。
    切 B 特写：B 视线避开 A 移到桌面，鼻翼翕动一次，长停顿 2 秒。
    切 B 中景：B 抬眼回 A："…我以为有别的办法。"
    切 A 单人：A 沉默看 B，下颌咬紧，未答。' — 机位切换 + 对白文本 + lip-sync + 反应
