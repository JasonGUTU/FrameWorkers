# action_fight

> 适用场景：肉搏 / 持械打斗 / 追逐 / 拦截 / 闪避。强调速度感、力量传递、命中反馈。

## STYLE HEADER 候选词
高速动作 / 单镜头长镜 / 手持跟随 / 命中冲击 / 武打实拍质感 / 肉感物理 / 速度模糊（有限使用）

## 词汇表

**攻击动词链**：起手 → 蓄力 → 挥出 → 命中 → 反震 / 抽肋 / 横扫 / 直贯 / 上挑 / 下劈 / 锁喉 / 摔投 / 弹腿 / 闪身错开

**身体力学**：腰胯发力 / 肩部沉肘 / 步法移动半步 / 重心下沉 / 借力反推 / 关节锁死 / 反手扣腕

**命中反馈帧（最关键，必写）**：拳风带起发丝 / 衣料褶皱被冲击波散开 / 击中刹那身体凹陷 0.1 秒 / 唇角血珠飞溅 / 抵挡时虎口震麻 / 武器对碰火星

**镜头语言**：手持跟随 / whip pan（瞬移横甩） / 跨轴跟随 / 命中瞬间镜头微抖 0.05 秒 / 拉远显交手关系 / 推近显疼痛 / 摔投跟随翻滚 360 度

**节奏控制**：3 拳 1 闪 / 攻防互换 / 短促爆发 + 静止 1 帧（冲击力靠停顿）

## panel 节奏建议
- 4-panel 推荐结构：**起手 → 第一击命中 → 反击交换 → 决定性一击 / 锁定**
- 每 beat 必须包含：
  1. 攻击者动作（动词链 + 身体力学）
  2. 被攻击者反应（命中反馈帧 + 失衡 / 反推）
  3. 镜头跟随（whip pan / 推 / 拉 / 抖 + 秒数）
- 节奏：单 beat 内可堆 2-3 个动作交换，不要每 beat 只有一拳
- 避免：模糊"激烈打斗" / 跳过命中反馈细节
