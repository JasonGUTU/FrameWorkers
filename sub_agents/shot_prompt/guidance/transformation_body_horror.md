## panel 节奏建议
- 4-panel 推荐结构：**触发 → 入侵 → 撕裂峰值 → 生长续发**
- 每个 beat 必须包含三层叠加：
  1. 角色身体变化（用上面动词表）
  2. 镜头反应（晃 / 失焦 / 推 / 微颤 + 秒数）
  3. 环境共振（嗡鸣 / 电弧 / 黑雾 / 空气塌陷）
- 时间精度：写到 0.1 秒级（"微颤 0.1 秒"、"拉丝悬停 0.2 秒后回缩"）
- 避免：抽象痛苦描述 / 整段静态 pose
