# inner_monologue_VO

> 适用场景：旁白 / 内心独白覆盖在 visual 上 —— 角色不开口，VO 揭示内心；通常配合主观视角 / 隐喻空镜 / 慢运镜。

## STYLE HEADER 候选词
旁白叙事 / 内心独白 / 主观视角（POV）/ 隐喻空镜 / 慢运镜 / 时间停滞感 / 散文化影像

## 词汇表

**VO 文本格式**：明确写出旁白内容（中文双引号），标注语气（"低沉自语" / "回忆式" / "疑问" / "颤抖"）；不要让角色嘴动配合 VO（嘴闭着）

**主观视角元素**：手持微晃模拟视线 / 视线落在某物上停顿 / 眨眼瞬间画面短暂变暗 0.2 秒 / 浅景深突显凝视对象 / 透过窗 / 帘 / 雾看出去

**隐喻 visual**：与 VO 内容形成对照或呼应的物 —— 飘落叶 / 烧到尽头的烟 / 滴水痕迹 / 风中翻书 / 蒙尘相框 / 空椅子 / 鞋印 / 影子 / 雨打窗

**时间感操控**：慢动作（0.5x）/ 抽帧（每 6 帧抽 1）/ 单帧停滞（关键象征物前停 1 秒）/ 时间反向（局部）/ 现实 + 闪回叠化

**镜头**：极慢推进 / 慢轨道横移 / 升降揭示纵深 / 焦点拉换揭示新元素 / 静止长镜

**角色处理**：背影 / 侧面剪影 / 仅手部出现 / 脸部不清晰；如有脸部，**嘴必须闭合**

## panel 节奏建议
- 4-panel 推荐结构：**触景 → 闪回 / 联想 → 顿悟 / 转折 → 余韵**
- 每 beat 必须包含：
  1. visual 元素（隐喻物 / 主观视角对象）+ 镜头慢动作处理
  2. VO 文本（双引号 + 语气）
  3. 时间感处理（慢动作 / 停滞 / 抽帧 之一）
- 关键约束：角色**嘴必须闭合**；VO 文本和 visual 形成对照或呼应而不是同义重复
- 避免：角色边走边说出声 / VO 文本是 visual 的字面描述

## SFX 词汇
环境音稀薄化 / VO 清晰但近耳 / 心跳放慢 / 钟摆 / 远处人声模糊 / 室内寂静 / 风穿过缝隙 / 单滴水声 / 旧物轻响

## 反面教材
❌ "主角走在街上回忆童年"        — 没 VO 文本 / 没隐喻 visual / 没时间处理
✅ '主观视角微晃，镜头穿过雨打的玻璃看出去：街对面有人撑红伞慢慢走过（慢动作 0.5x）；
    VO 低沉自语："那年她也撑过同样一把伞。"
    焦点从玻璃水珠拉到远处红伞，水珠失焦时 VO 第二句："…只是当时我没回头。"' — 隐喻物 + VO 文本 + 慢动作 + 焦点切换
