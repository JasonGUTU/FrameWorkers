# emotional_close_up

> 适用场景：情绪驱动特写 —— 微表情转变 / 内心波动 / 决定性瞬间 / 凝视 / 哽咽。

## STYLE HEADER 候选词
极慢推进 / 呼吸感 / 光影感强 / 大面部占比 / 静默叙事 / 浅景深 / 半边脸阴影

## 词汇表

**微表情**：嘴角抽动 / 瞳孔放大或收缩 / 鼻翼翕动 / 眉峰挑起 / 眉头微锁 / 喉结滑动 / 睫毛颤动 / 下颌咬紧 / 太阳穴紧绷 / 唇缝微张 / 眼底湿润反光

**视线变化**：先盯着远方 / 视线缓慢下移 / 瞬间对焦观众 / 瞳孔追随对方移动 / 闭眼 0.5 秒再睁开 / 眨眼但只闭一半

**光影**：眼神光偏移 / 半边脸阴影渐深 / 顶光照亮额头 / 侧逆光勾轮廓 / 高光从颧骨滑过 / 反射光在虹膜里晃动

**呼吸**：屏息 1 秒 / 急促呼吸 / 长叹 / 哽咽吞咽 / 吸气时肩膀微抬 / 呼气时鼻翼塌陷

**镜头**：极缓推进（推到鼻尖距离）/ 静止不动 / 焦点从眉到唇缓慢偏移 / 轻微 dolly

## panel 节奏建议
- 4-panel 推荐结构：**平静 → 内化 → 爆发 → 余波**
- 每 beat 必须包含三层：
  1. 微表情（用上面词汇表中 1-2 个具体动作）
  2. 视线 / 呼吸状态变化
  3. 光影微变（眼神光偏移 / 阴影深浅）
- 关键约束：**镜头几乎不动**，所有戏在表情和光里
- 避免：动作幅度大 / 多次切镜 / 表情形容词（"难过 / 愤怒"）
