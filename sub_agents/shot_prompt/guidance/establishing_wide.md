# establishing_wide

> 适用场景：场景建立 / 环境氛围 / 空间关系 / 时间感建立 / 角色入场 / 收尾空镜。角色在画面里占比小或无。

## STYLE HEADER 候选词
广角风景 / 史诗景深 / 大气宽幅 / 静默空镜 / 极简构图 / 极远景 / 缓慢平移 / 长焦压缩

## 词汇表

**色彩关系**：冷暖对比（蓝 + 橙） / 单色调统一（全灰蓝 / 全土黄）/ 局部高饱和点 / 渐变天空 / 暗调画面 + 一点暖光源

**景深层次**：前景剪影（树枝 / 栏杆 / 草丛）/ 中景主体（建筑 / 角色）/ 后景大气透视（远山 / 雾 / 大气模糊）/ 三层都有元素

**环境动态**：风吹草动 / 雪花飘落 / 烟雾飘移 / 旗帜翻卷 / 树叶旋转下落 / 远处雷光 / 鸟群飞过 / 水面涟漪

**光线**：黄金时刻侧光 / 顶光高反差 / 阴天平光 / 月光蓝调 / 雾中漫反射 / 逆光剪影 / 窗光地面投影

**镜头**：缓慢平移（左 → 右 30 秒级别慢）/ 静止 + 内部元素动 / 极慢推进 / 升降镜头揭示纵深 / 长焦把远景压扁

**角色处理**：背影 / 远景小到 1/10 画面 / 不入画或仅腿部入画 / 与环境融合（站在悬崖边 / 在大门下显小）

## panel 节奏建议
- 4-panel 推荐结构：**远景全貌 → 中景细节 → 局部重点 → 暗示元素（铺梗 / 留白）**
- 每 beat 必须包含：
  1. 三层景深关系（前 / 中 / 后景元素都列）
  2. 色彩对比关系（哪两色 / 高饱在哪）
  3. 环境动态（风 / 烟 / 光变 / 飘落物 之一）
- 关键约束：**几乎无角色动作**；如有角色，是静态站立或缓慢移动
- 避免：人脸特写 / 戏剧性事件 / 快速运镜
