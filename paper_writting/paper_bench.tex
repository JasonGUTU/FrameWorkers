\section{FrameWorkers-Bench: Sub-agent Routing Benchmark}
\label{sec:bench}

We evaluate director routing as a standalone task: given a natural-
language user goal $g$ for a video deliverable, produce the ordered
chain of sub-agents whose composition satisfies it. Routing is
combinatorial over a closed vocabulary of $20$ agents and multi-step
(plans range from $2$ to $10$ agents); routing errors compound
downstream because each agent consumes specific upstream artifacts.

\paragraph{Agents.}
The inventory $\mathcal{A}$ contains $20$ agents across modalities:
text (Story, Screenplay, Narration, Translation), image
(Illustration, KeyFrame, IntakeImage, BriefEnricher), video (Video,
IntakeVideo, VideoAnalysis, StyleTransfer, VideoExtend, Highlight),
audio (Music, Ambience, Narrator, AudioMix, Transcription), and
final composition (Compositor). Each agent carries a typed descriptor
specifying its \texttt{Inputs}, \texttt{Output}, and
\texttt{Purpose / Trigger}; the descriptors are concatenated verbatim
into the planner's system prompt.

\paragraph{Task.}
A planner $\pi$ maps $g$ to an ordered chain
$\hat{\mathbf{c}} = (\hat{c}_1, \dots, \hat{c}_n)$ with
$\hat{c}_i\!\in\!\mathcal{A}$. Hard structural constraints: each
$\hat{c}_i$ appears at most once in a plan; the chain length is bounded
by $n\!\le\!20$; no branching or parallelism. User text input is
already represented as a global \texttt{[creative\_brief]} artifact, so
plans start at the first content-producing agent rather than from a
text-intake step.

\paragraph{Evaluation set.}
$522$ hand-authored goals span $44$ canonical chain shapes
(e.g.\ \emph{cinematic film}: Story$\to$Screenplay$\to$KeyFrame$\to$Video$\to$Compositor;
\emph{illustrated storytelling}: Narration$\to$Illustration$\to$Narrator$\to$Compositor;
\emph{video edit + subtitle}: IntakeVideo$\to$Transcription$\to$Translation$\to$Compositor),
with chain length ranging from $2$ to $10$ agents (mean $6.0$),
distributed across eleven task categories — \emph{complex}
(multi-modifier compositions, $95$), \emph{cr} (creative mini-drama,
$80$), \emph{storytelling} (illustrated audiobook, $80$),
\emph{intake\_img} (image-referenced, $51$), \emph{highlight}
(highlight reel, $48$), \emph{style} (style transfer, $38$),
\emph{extend} (video extend, $34$), \emph{sub} (monolingual subtitle
on synthesised video, $25$), \emph{sub\_vid} (subtitle on
user-uploaded video, $25$), \emph{bilingual} (bilingual subtitle,
$25$), and \emph{audio} (audio-track edit, $21$) — and modifier
flags (bilingual, music, ambience, image-reference, longstory). The
set is held-out and is enforced to have zero overlap (under text
normalization) with the training corpus.

\paragraph{Training corpus.}
We release two training splits derived from the \emph{same}
$44$-shape blueprint as the eval set, both hand-authored under a
per-shape budget of $\max(20,\,10\!\times\!\text{eval\_count})$ so
long-tail shapes (single-eval cases) still receive $20$ training
samples. The \emph{SFT split} contains $1{,}417$ messages-format
samples with the same eleven-category mix as the eval set
(\emph{complex} $256$, \emph{storytelling} $219$, \emph{cr} $218$,
\emph{intake\_img} $138$, \emph{highlight} $130$, \emph{style}
$103$, \emph{extend} $92$, \emph{sub} $68$, \emph{bilingual} $68$,
\emph{sub\_vid} $68$, \emph{audio} $57$); $\approx 120$ of those are
\emph{long-story} samples whose user goal is a full $\approx
2{,}500$-word original narrative, mirroring the eval's long-input
distribution. The \emph{GRPO split} contains $1{,}396$ prompts (a
hand-written GRPO seed corpus plus a stratified-random reuse of SFT
user goals) with category counts \emph{complex} $254$, \emph{cr}
$215$, \emph{storytelling} $211$, \emph{intake\_img} $136$,
\emph{highlight} $128$, \emph{style} $103$, \emph{extend} $91$,
\emph{sub\_vid} $68$, \emph{bilingual} $67$, \emph{sub} $67$,
\emph{audio} $56$. User goals are unique within each split and
disjoint from the $522$ eval goals; details of the SFT and GRPO
learning recipes are in \S\ref{sec:sft} and \S\ref{sec:grpo}.

\paragraph{Metrics.}
A gold chain $\mathbf{c}^*$ is a sequence in which positions may be
\emph{set-valued}: $c^*_i$ is either a single agent or a set of
interchangeable agents (e.g.\ $\{$Music, Ambience$\}$ when the audio
slot tolerates either ordering). For a predicted chain $\hat{\mathbf{c}}$
we report three complementary scores:
\begin{align}
\text{chain\_acc}(\hat{\mathbf{c}},\mathbf{c}^*) &= \mathbb{1}\!\big[\hat{\mathbf{c}}\!\equiv_\text{set}\!\mathbf{c}^*\big], \\
\text{step\_acc}(\hat{\mathbf{c}},\mathbf{c}^*) &= \frac{|\{i\,:\,\hat{c}_i\in c^*_i\}|}{\max(|\hat{\mathbf{c}}|,\,|\mathbf{c}^*|)}, \\
\text{edit}(\hat{\mathbf{c}},\mathbf{c}^*) &= \mathrm{Lev}_{\!\equiv_\text{set}}(\hat{\mathbf{c}},\mathbf{c}^*).
\end{align}
$\equiv_\text{set}$ requires identical length and per-position
agent-set membership; the $\max$ denominator in step\_acc penalizes
length mismatches symmetrically. The third score is the
set-aware Levenshtein distance: insertions, deletions, and
substitutions all cost $1$, with $\hat{c}_i\!\equiv_\text{set}\!c^*_j$
when $\hat{c}_i\!\in\!c^*_j$. \emph{step\_acc} is strictly positional
(a single insertion mid-chain shifts every downstream slot and
appears as many wrong positions), whereas \emph{edit} is alignment-
aware (the same insertion costs $1$); reporting both separates
"plan-shape was right but a wrong agent was inserted" from "wrong
agents at the wrong positions throughout".

\paragraph{Reference configuration.}
All non-LoRA reference systems are queried with the canonical core
prompt — no worked-example fewshots, no policy scaffolding, no
topology hints — byte-identical to the prompt used during LoRA
training and inference, so any score difference reflects model
capability rather than template memorization.\footnote{Adding
fewshots, policy scaffolding, and topology hints to the prompt lifts
Gemini~2.5 Flash from $74.7\%$ to $84.7\%$ chain\_acc on this set,
but the lift is template-driven and does not transfer to the LoRA
training distribution; we therefore adopt the unscaffolded core
prompt as the reference configuration. Cross-model scores under this
configuration are reported in \S\ref{sec:eval}, Table~\ref{tab:director_routing_v4500}.}
